# McGraw Hill Connect｜業務推廣經驗分享

華泰文化 張維峻的沉浸式業務分享網頁。

此版本包含「推廣藍圖」導覽文字，並將原始簡報最後兩頁納入正式章節。

## 內容

- 推廣成果與三校採用案例
- 互動合作流程與採用後追蹤
- 教師版及學生版推廣影片
- 未來推廣藍圖
- 完整成果原圖與感謝聆聽圖片
- 簡報模式與講者提示

## 本機預覽

本網站使用原生 HTML、CSS 與 JavaScript，不需要安裝套件或執行建置。

在此資料夾執行：

```bash
python -m http.server 8000
```

在瀏覽器開啟 `http://localhost:8000`。

## 檔案

- `index.html`：網頁內容與章節。
- `styles.css`：桌機及手機版面。
- `app.js`：流程切換、案例切換、影片及簡報操作。
- `data.js`：案例資料與講者提示。
- `assets/`：完整圖片、影片與原始投影片 PDF。

## 資料說明

三校採用量依原簡報加總為 213 個。營收依原簡報結尾成果圖列示 366,600 元。案例價格為簡報當時方案。

校園示意圖、成果圖及兩支影片均來自使用者提供的簡報。教師影片保留完整內容與原音，轉為網頁播放尺寸。

此備份包含網站顯示所需的全部素材，不包含網站平台專用設定、憑證或原始儲存庫歷史。
